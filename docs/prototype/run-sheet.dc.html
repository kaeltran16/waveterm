rules held across all states
  • One authority on state: the verb, the meter and next: are derived from the same read and can never disagree.
  • The goal is printed once, never repeated by an attribution line or a run bar.
  • A degraded read says what it cannot see; it never falls back to the launch snapshot.
  • Config is a printed line until you ask for the dials. Fixed settings state their reason where the dials would be.
  • Failure text is one line in the row's own state column, not two lines above the task.
