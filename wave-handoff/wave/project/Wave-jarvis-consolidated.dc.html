Wave · Jarvis consolidation · interaction design

One surface, one thread: the run, its record, and the recall are the same conversation

Channels, Jarvis, Tasks and Graph collapse into a single destination — not into four sub-tabs. The Stage holds one persistent thread where worker narration and Jarvis answers interleave; the task record is a band docked above it, not a destination; the graph is a peek you enter from any object and leave by opening one. One composer, one roster, one autonomy control, one grounding treatment.

The failure mode this avoids

A Runs │ Recall │ Tasks │ Graph switch would shorten the nav rail and move every hop one level inward. There is no such switch here. The thread is one region that never swaps out; the record expands above it; the graph floats over it; the composer retargets in place.
