Interaction rules

  • openrouter is always first and the default; its 'installed' state = the OpenRouter API key is present (not in the harness catalog).
  • Uninstalled harnesses stay visible but disabled: not installed tag, reduced emphasis, no hover accent, not selectable.
  • Selected harness row gets the accent border + surface-hover fill + check, matching the theme picker language.
  • Model fields enable only for openrouter; any harness selection locks them with an openrouter only hint in place of Save.
  • Key-missing warning (amber, with label) shows only when runtime = openrouter and the key is missing.
